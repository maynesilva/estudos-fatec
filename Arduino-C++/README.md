# Projetos Arduino em C++

Esta pasta reúne pequenos projetos desenvolvidos em **Arduino** utilizando **C++** como linguagem de programação.  
Os circuitos foram criados como parte de um projeto de extensão na FATEC e servem para praticar lógica de programação aplicada a hardware.

---

## 📂 Projetos

### 🚦 Semáforo
- **Descrição:** LEDs simulando um semáforo (vermelho, amarelo e verde).
- **Componentes:** Arduino Uno, 3 LEDs, resistores, jumpers, protoboard.
- **Objetivo:** Treinar lógica de temporização com `delay()` e controle de saídas digitais.

### 💡 LED Simples
- **Descrição:** Acender um LED com Arduino.
- **Componentes:** Arduino Uno, LED, resistor, protoboard.
- **Objetivo:** Introdução ao uso de pinos digitais.

### 🔘 Botão de Acionar
- **Descrição:** LED acende quando o botão é pressionado.
- **Componentes:** Arduino Uno, LED, botão, resistores, protoboard.
- **Objetivo:** Aprender leitura de entradas digitais e interação com saídas.
