# Projetos Arduino em C++

Esta pasta reúne pequenos projetos desenvolvidos em **Arduino** utilizando **C++** como linguagem de programação.  
Os circuitos foram criados como parte de um projeto de extensão na FATEC e servem para praticar lógica de programação aplicada a hardware.

---

## 📂 Projetos

### 🚦 Semáforo
- **Descrição:** LEDs simulando um semáforo (vermelho, amarelo e verde).
- **Componentes:** Arduino Uno, 3 LEDs, resistores, jumpers, protoboard.
- **Objetivo:** Treinar lógica de temporização com `delay()` e controle de saídas digitais.

### 💡 LED Simples
- **Descrição:** Acender um LED com Arduino.
- **Componentes:** Arduino Uno, LED, resistor, protoboard.
- **Objetivo:** Introdução ao uso de pinos digitais.

### 🔘 Botão de Acionar
- **Descrição:** LED acende quando o botão é pressionado.
- **Componentes:** Arduino Uno, LED, botão, resistores, protoboard.
- **Objetivo:** Aprender leitura de entradas digitais e interação com saídas.

### 🚗 Potenciômetro como Controle de Volume
- **Descrição:** Potenciômetro simula o ajuste de intensidade/volume, variando o brilho de um LED.
- **Componentes:** Arduino Uno, potenciômetro, LED, resistor, protoboard, jumpers.
- **Objetivo:** Demonstrar como entradas analógicas podem controlar saídas PWM (analogWrite), relacionando com sistemas reais como controle de som ou potência.

### 🌙 Poste com LDR
- **Descrição:** LED acende automaticamente quando o ambiente fica escuro, utilizando um sensor de luminosidade.
- **Componentes:** Arduino Uno, LDR, LED, resistores, protoboard, jumpers.
- **Objetivo:** Aprender a usar sensores analógicos para automação simples e controle de saída digital.

### 🎚️ Potenciômetro Controlando LEDs
- **Descrição:** LEDs acendem progressivamente conforme o valor do potenciômetro aumenta e apagam conforme diminui.
- **Componentes:** Arduino Uno, potenciômetro, 5 LEDs, resistores, protoboard, jumpers.
- **Objetivo:** Aplicar leitura analógica (analogRead) e lógica condicional para controlar múltiplas saídas digitais.
