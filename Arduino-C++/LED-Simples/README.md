# Projeto LED Simples 💡

## 📖 Descrição
Este projeto acende um LED utilizando o Arduino.  
Foi desenvolvido em **Arduino** com **C++**, como parte dos estudos de programação aplicada a hardware.

## 🛠️ Componentes
- Arduino Uno
- LED
- Resistor
- Protoboard
- Jumpers

## 🎯 Objetivo
Aprender a:
- Configurar pinos como saída (`pinMode`)
- Controlar um LED com `digitalWrite`
- Entender o funcionamento básico de circuitos digitais

## 📂 Estrutura
LED-Simples/

└── led_simples.ino   # Código do projeto

└── README.md         # Documentação do projeto

## 🚀 Funcionamento
- O LED está conectado ao pino **13** do Arduino.  
- O código configura esse pino como saída.  
- O LED acende e apaga conforme a lógica definida no programa.
